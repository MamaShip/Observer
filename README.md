**[官网 → ob.portkey.click](https://ob.portkey.click)**

想留存的微信公众号文章，可以在原文还能打开时，把链接交给折光观察者。它会保存文章，并在观察期内定期检查可访问性。如果文章被删除，你会收到邮件，也可以回来阅读之前保存的备份。

## 保存第一篇文章

1. **登录官网。** 官网目前采用邀请制。请已加入的朋友在「设置」里填写你的邮箱。打开邀请邮件，点击「接受邀请并注册」即可进入「我的观察」。链接 7 天内有效，以后用邮箱验证码登录。
2. **复制文章链接。** 在微信里打开一篇公开的公众号文章，点右上角「···」，选择「复制链接」。

   <img src="./web/src/assets/help/copy-link.png" width="300" alt="微信文章右上角「···」菜单，第二行有「复制链接」">

3. **开始观察。** 在官网的「我的观察」里粘贴链接，点「开始观察」。备份完成后，打开这篇文章的详情就能阅读，也可以下载为单个 HTML 文件离线阅读，或用浏览器打印成 PDF。

默认的观察期为 60 天。观察结束后，已有备份仍然可以阅读和下载。

## 在微信里使用

站点开通了公众号入口，也可以直接在微信里把文章链接发给公众号，不用打开网页。

<img src="./web/public/wechat-qr.jpg" width="160" alt="折光观察者公众号二维码，用微信扫码关注">

1. **关注公众号**，按回复里的「绑定邮箱」链接登录并确认。绑定后，您的邮箱账号会和微信账号建立关联，删除提醒也会发到这个邮箱。
2. **发送文章链接。** 在文章右上角「···」里选择「复制链接」，粘贴发给公众号，公众号会回复备份结果和观察页面的链接。

回复里的链接打开的是折光观察者的官网。微信可能提示"该网站未完成ICP备案"，可以放心继续访问。
公众号不能主动发消息，文章被删除时仍以邮件通知。
1. 发送「我的」查看最近的观察，发送「解绑」解除绑定，也可以在网站的「设置」里解除。

还没绑定就发来的链接会暂时记下，绑定完成后自动开始观察。回复里的链接点开即可进入，不用重复登录，24 小时内有效，请不要转发给别人。

## 创建自己的独立观察者

欢迎任何人用这个项目创建自己的观察者。你可以只给自己用，也可以邀请朋友一起保存各自关心的文章。站点用什么名字、向谁开放、备份存在哪里，都由你决定。搭建自己的站点无需官网账号或邀请。

准备好服务器和域名后，可以跟随部署指南配置邮件和存储，启动站点，再开通第一个账号。[搭建自己的观察者](docs/runbook.md#首次部署)
